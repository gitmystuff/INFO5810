Activity 1

Querying Wikidata with SPARQL

Explore Wikidata's query service using Q-numbers and property identifiers. Start with the built-in cats example, then write your own query.

Activity 2

Querying DBpedia with SPARQL

Wikipedia as a knowledge graph. Explore RDF triples mined from infoboxes, follow URIs, and bridge to Wikidata via owl:sameAs.

dbpedia.org/snorql dbo: · dbr: URI navigation owl:sameAs
