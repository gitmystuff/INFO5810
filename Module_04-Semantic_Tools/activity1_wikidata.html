query.wikidata.org INFO 5810
Part 1 — Together  ·  Instructor walkthrough
1
Open the Wikidata Query Service

Navigate to query.wikidata.org in your browser. This is the live SPARQL endpoint — you're querying over 100 million items in real time.

You should see an editor pane on the left and a results panel on the right. The interface is called WDQS (Wikidata Query Service).

2
Load a starter example — Cats

Click the Examples button in the toolbar. In the dropdown, select "Cats". This replaces whatever is in the editor with a working SPARQL query.

Don't run it yet. Read through it first.

3
Read the query together

Break down each part line by line:

#Cats
SELECT ?item ?itemLabel
WHERE {
  ?item wdt:P31 wd:Q146 .
  SERVICE wikibase:label {
    bd:serviceParam wikibase:language "[AUTO_LANGUAGE],en" .
  }
}
#CatsA comment — human-readable label, ignored by the engine
SELECTDeclares what to return — ?item (the URI) and ?itemLabel (human name)
wdt:P31The property "instance of" — P31 in Wikidata's property vocabulary
wd:Q146The entity "domestic cat" — every Wikidata entity has a Q-number
SERVICEA Wikidata extension that automatically fetches human-readable labels for any QID
Key idea — Read the triple as a sentence: "Find every ?item where instance-of = domestic cat." Variables start with ?. Properties (P31) and entities (Q146) are URIs.
4
Run the query

Click the blue ▶ Run button (or press Ctrl+Enter / Cmd+Enter). Results appear in the panel below the editor.

Each row is a Wikidata item — a specific cat that someone has documented in the knowledge graph. The ?item column contains the full URI; ?itemLabel shows the name.

5
Modify it: cats → dogs

Change wd:Q146 to wd:Q144. Q144 is the Wikidata entity for domestic dog.

#Dogs now
SELECT ?item ?itemLabel
WHERE {
  ?item wdt:P31 wd:Q144 .
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],en" . }
}
Tip — Type Ctrl+Space after wd: to trigger autocomplete. You can search by label (e.g. "domestic dog") without needing to memorize Q-numbers.

Run the modified query. Observe: the structure is identical, only the value changed. That's what makes SPARQL compositional.

Part 2 — On Your Own  ·  Continue from here
6
Add a second triple pattern

Extend the query to return only notable dogs from a specific country. Add a second triple in the WHERE block using wdt:P17 (country) to filter:

?item wdt:P31 wd:Q144 .
?item wdt:P17 wd:Q34 . # Q34 = Sweden — try your own country

Use Ctrl+Space to find your own country's Q-number. Run and see how the result set changes.

7
Switch to a visualization

Click the eye icon (Display options) below the results table. Try switching between views:

  • Table — the default grid view
  • Map — plots items with geographic coordinates (add wdt:P625 ?coords to your query if the map is empty)
  • Image grid — shows photos if items have wdt:P18 (image)
Prompt — What does choosing a visualization type say about which properties matter for a given question?
8
Write your own query from scratch

Pick any category of thing you're curious about. Find its Q-number using Ctrl+Space autocomplete. Write a query that returns at least two columns and uses at least one triple pattern beyond wdt:P31.

Ideas: Nobel laureates born after 1980 · Volcanoes in Japan · Films directed by a specific director · Endangered bird species

Remember — SELECT ?item ?itemLabel ?someOtherProp lets you add columns. Each column needs a corresponding triple in the WHERE block.
9
Save your query URL for submission

Once your query runs successfully, click the Link icon in the toolbar. This generates a shareable URL that encodes your exact query.

Copy that URL and paste it into the submission form along with a one-sentence description of what your query finds and why you chose it.
